### 前置：Rinx 在哪跑

| 平台 | 怎么拿 | 备注 |
|---|---|---|
| macOS | `git clone` Rinx → `brew install cmake` → `cargo run --locked --features agent_chat` | 官方原生验证记录就是 macOS |
| Android | 仓库 `mobile/` 脚本（需自签配置） | 不强制手机演示 |
| 桌面无 Rust | 用 GOSIM 公布的 OctoSense 桌面环境（开营说明里发） | 不听课也能拿到 |

- Rinx 是 **Matrix IM 客户端**（WeChat 风格 UI），首次要一个 Matrix homeserver 账号（支持 Sliding Sync 的自建/官方试用服；报名/开营说明里会发临时账号，没发就在 matrix.org 注册一个免费账号）
- 登录：Rinx 内直接填 server URL + user + password

### 分享 URL 卡片的 4 步（对应官方 4 条要求）

1. **打开一个聊天会话**（DM 或群都行）
2. **点聊天输入框旁的 `+`** → 选"网页卡片 / Web Card / 应用分享"（Rinx 支持分享 HTTP(S) 地址，页面**不会**因此拿到聊天记录或账号权限）
3. **填 `intentflow-card.pages.dev`**（裸域名或完整 URL 均可，Rinx 会生成一张卡片进会话）→ 确认发送
4. **接收方视角**：对方（或你自己的另一个账号）在会话里点卡片 → 浏览器/内嵌视图打开卡片页 → 页内完成 3 个联动动作

### 机制课核心（不听课，知道这 5 句就够答辩用）

1. **OctoSense**：Agent 交互 Shell，保留熟悉应用入口，数据/卡片/操作围绕意图组织（"人在回路"：重要决定留给用户）
2. **Octoscript L0**：声明式描述界面/状态/交互；L0 路径 = 模型写布局与数据绑定，**事实由数据能力提供**（no-facts：不得编造状态/操作结果）
3. **octos**：Agent harness（上下文/工具/任务/多 Agent 协作/审批）；**OctoLoop** = 内环执行（便宜模型可重跑）+ 外环审查（强模型只花判断），每个 commit 过两双眼睛
4. **Rinx**：本届主要宿主，网页卡片可分享 HTTP(S) 地址，**页面不继承账号权限、不读聊天记录**；原生小程序需扩展宿主（本作品走网页卡片，不碰原生）
5. **hagency**：软件工厂协作（多 Agent 任务/沟通/交接/人工确认）——只有"软件协作"选题才需要接，财经/新闻/日历不强制

> 答辩时把 5 句翻译成"我为什么选网页卡片形态"：不碰原生扩展 = 不赌宿主版本，URL 卡片官方明确允许且"现阶段评审以可运行作品为准"。
